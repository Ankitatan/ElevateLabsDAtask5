# Task 5: Exploratory Data Analysis (EDA) — Titanic Dataset

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset as part of a Data Analyst Internship. The goal is to understand the data, identify patterns, explore relationships between variables, and extract meaningful insights using statistical analysis and visualizations.

## 🎯 Objectives
- Understand the dataset structure and summary statistics.
- Identify missing values and potential outliers.
- Analyze passenger characteristics and survival patterns.
- Explore relationships between variables using visualizations.
- Examine correlations among numerical features.
- Summarize key findings from the analysis.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Project Files
- `Titanic_EDA_Task5.ipynb` — Jupyter Notebook containing the analysis and visualizations.
- `Titanic_EDA_Findings_Report.pdf` — PDF report summarizing the analysis and observations.

## 📊 Analysis Performed
1. Dataset inspection using `.info()` and `.describe()`
2. Missing-value analysis
3. Categorical analysis using `.value_counts()`
4. Histograms and count plots
5. Boxplots for distribution and outlier exploration
6. Survival analysis by passenger sex and class
7. Scatterplots to explore relationships between age and fare
8. Correlation heatmap and pairplot

## 🔍 Key Questions
- Which passenger groups had higher survival rates?
- How did survival vary by sex and passenger class?
- What patterns appear in passenger age and fare distributions?
- Which variables show relationships or correlations?
- Are there missing values or potential outliers?

## 🚀 How to Run
1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

3. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open `Titanic_EDA_Task5.ipynb` and run the cells from top to bottom.

## ✅ Conclusion
This project demonstrates core EDA techniques, including data inspection, missing-value analysis, descriptive statistics, visual exploration, correlation analysis, and insight summarization.
